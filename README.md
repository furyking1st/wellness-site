# Nguyen Son’s Wellness and Physiotherapy Website

This is the personal wellness and physiotherapy website of Nguyen Son, a physiotherapist based in Ho Chi Minh City. It is a standalone project, separate from SonNexus (sonnexus.space).

This commit only initializes the repository. There is no site content yet. The G1 brief will define the colors, fonts, and components independently of the SonNexus neon palette.

The site will follow the /web v0.3 workflow in this order.

1. G1 brief
2. Build
3. Cross-check
4. Preview
5. Review
6. Deploy to the VPS
